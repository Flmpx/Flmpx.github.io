示例程序(main.c):  
```c
#include <stdio.h>

int main(int argc, char* argv[])
{
    printf("argc = %d\n", argc);
    for (int i = 0; i < argc; i++) {
        printf("arg[%d] = %s\n", i + 1, argv[i]);
    }

    return 0;
}
```

示例目录:  
```txt
.
├── .vscode/
│   ├── launch.json      # 调试配置
│   ├── settings.json    # 设置
│   └── tasks.json       # 生成任务配置
├── CMakeLists.txt     
├── main.c               # 主程序
└── bin/                 # 我这里生成的可执行文件都放在bin目录下
```

## 使用VS Code自带的调试

### 运行

在vscode中运行程序一般和上面[直接使用可执行文件](#直接使用可执行文件)时一样的, 这里不过多赘述  

### 调试 

第一步, 选中调试并选中创建一个 `launch.json` 文件, 然后选择 `C++(GDB/LLDB)`    
![](../../image/vscode/Pasted%20image%2020261101090415.png)

然后选择 `C/C++: (gdb) 启动`, 如果消失了可以点击右下角的添加配置    
![](../../image/vscode/Pasted%20image%2020261101090535.png)

之后将内容改成这样  
```json
{
    // 使用 IntelliSense 了解相关属性。 
    // 悬停以查看现有属性的描述。
    // 欲了解更多信息，请访问: https://go.microsoft.com/fwlink/?linkid=830387
    "version": "0.2.0",
    "configurations": [
        {
            "name": "(gdb) 启动",
            "type": "cppdbg",
            "request": "launch",
            
            // 这个需要修改, gdb需要知道你程序的位置
            "program": "${fileDirname}/bin/${fileBasenameNoExtension}.exe",
            
            // 这里就是加参数的地方
            "args": [
	            "abc", "def", "1", "2"
            ],
            "stopAtEntry": false,
            "cwd": "${fileDirname}",
            "environment": [],
            "externalConsole": false,
            "MIMode": "gdb",
            
            // 这个时gdb的位置, 如果你配了环境变量的话, 直接写gdb, 没用配就写gdb程序的位置
            "miDebuggerPath": "gdb",
            "setupCommands": [
                {
                    "description": "为 gdb 启用整齐打印",
                    "text": "-enable-pretty-printing",
                    "ignoreFailures": true
                },
                {
                    "description": "将反汇编风格设置为 Intel",
                    "text": "-gdb-set disassembly-flavor intel",
                    "ignoreFailures": true
                }
            ]
        }
    ]
}
```

然后按 `F5` 开启调试, 然后看到argc的值是 5    
![](../../image/vscode/Pasted%20image%2020261101091223.png)

如果想不同时刻加不同的参数呢? 和制作tasks.json是一样的, 在 `.vscode/launch.json` 文件中多添加几个配置即可(name记得改名)  
![](../../image/vscode/Pasted%20image%2020261101091540.png)


## 使用CMake + VS Code + CMake Tools插件进行

CMakeLists.txt:   
```cmake
cmake_minimum_required(VERSION 3.28.3)

project(main)

set(SRC_LIST ${CMAKE_CURRENT_SOURCE_DIR}/main.c)

set(CMAKE_RUNTIME_OUTPUT_DIRECTORY ${CMAKE_CURRENT_SOURCE_DIR}/bin)

add_executable(main ${SRC_LIST})
```

### 运行  

和上面一样, 可以和上面[直接使用可执行文件](#直接使用可执行文件)一样的做法, 但是也可以和下面的调试一样加参数, 运行的时候也会自动带上的  

### 调试

#### 方法一(修改 `settings.json` )
快速, 但是会让所有的targe都带上一样的参数, 不好控制  


点开 `.vscode/settings.json` , 加上下面这个设置  
```json
"cmake.debugConfig": {
	"args": [
		"abc", "def", "1", "2"
	]
}
```

然后点击左下角的调试按钮, 就可以的, 看到argc的值是 5  
![](../../image/vscode/Pasted%20image%2020261101095550.png)


#### 方法二(修改 `launch.json` ) 

这个方法和上面的其实和[使用VS Code自带的调试](#使用VS Code自带的调试)中使用调试差不多, 就是使用VS Code自带的调试, 其实CMake Tools何尝不是使用的VS Code的调试呢?  



创建 `.vscode/launch.json` 的方法和==使用VS Code自带的调试==中的内容是差不多的, 不过添加 `C/C++: (gdb) 启动` 后修改的内容不同  
```json
{
    // 使用 IntelliSense 了解相关属性。 
    // 悬停以查看现有属性的描述。
    // 欲了解更多信息，请访问: https://go.microsoft.com/fwlink/?linkid=830387
    "version": "0.2.0",
    "configurations": [
        {
	        // 名字建议改一下
            "name": "CMake Debug",
            "type": "cppdbg",
            "request": "launch",
            
            // 区别就在这里, 调试目标要进行修改
            "program": "${command:cmake.launchTargetPath}",
            "args": [
                "abc", "def", "1", "2"
            ],
            "stopAtEntry": false,
            "cwd": "${fileDirname}",
            "environment": [],
            "externalConsole": false,
            "MIMode": "gdb",
            "miDebuggerPath": "gdb",
            "setupCommands": [
                {
                    "description": "为 gdb 启用整齐打印",
                    "text": "-enable-pretty-printing",
                    "ignoreFailures": true
                },
                {
                    "description": "将反汇编风格设置为 Intel",
                    "text": "-gdb-set disassembly-flavor intel",
                    "ignoreFailures": true
                }
            ]
        }
    ]
}
```

然后点击左侧栏中CMake Tools的图标, 选中要调试的目标, 然后右键点击调试, 当然也可以按 `F5` 然后进行调试    
![](../../image/vscode/Pasted%20image%2020261101102840.png)

看到argc的值是 5  
![](../../image/vscode/Pasted%20image%2020261101103010.png)


如果想不同时刻加不同的参数呢? 和上一个差不多, 在 `.vscode/launch.json` 中多加几个差不多配置就行了  
![](../../image/vscode/Pasted%20image%2020261101103422.png)




---
如何切换不同的调试配置呢?  


先关掉原来的调试, 你总不想两个调试同时开始吧, 如果你看得过来就看吧. 接着点击左侧栏的调试图标, 然后切换自己想要的调试配置,  最后再开启调试即可  
![](../../image/vscode/Pasted%20image%2020261101104640.png)
